# Repository and Git safety

- Inspect `git status` and relevant diffs before significant edits. Treat pre-existing and uncommitted changes as user work; understand and preserve them.
- Keep changes within the requested scope. Do not overwrite or discard unrelated work, generated/user-owned data, or configuration without justification.
- Never run destructive Git operations such as reset, clean, forced checkout, branch deletion, or history rewriting without explicit authorization.
- Do not commit, amend, push, or create a pull request unless explicitly instructed.
- Before finishing, review the final diff and report the files changed and checks performed.
